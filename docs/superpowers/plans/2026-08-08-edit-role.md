# Edit Role UI/UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Mengimplementasikan perombakan arsitektur "Sticky Sidebar Premium" pada halaman Edit Role dan Permission Matrix.

**Architecture:** Memodifikasi grid dua kolom lama di `edit.blade.php` agar kolom kiri (`minmax(0,320px)`) menjadi *sticky sidebar* dengan gaya *Hero Card*. Merombak gaya tabel matriks di `_permission-matrix.blade.php` menjadi *glassmorphism card* dengan pemisahan visual yang tajam.

**Tech Stack:** Laravel Blade, Tailwind CSS, Alpine.js

## Global Constraints
- Dilarang menggunakan utilitas warna usang (`text-ink`, `bg-paper`, `text-brass`, `signal-amber`).
- Harus memakai standar token baru (`brand-600`, `gray-900`, `gray-500`, `amber-500`).
- Pastikan interaktivitas checkbox (`x-model`, dll) dari Alpine.js `roleForm` tidak rusak.

---

### Task 1: Restrukturisasi `edit.blade.php` (Sticky Sidebar)

**Files:**
- Modify: `resources/views/admin/roles/edit.blade.php`

**Interfaces:**
- Consumes: Blade Layout

- [ ] **Step 1: Hapus `<x-panel>`.** Bongkar elemen `x-panel` lama yang membungkus *form* utama.
- [ ] **Step 2: Terapkan Sticky Sidebar.** Buat *container* kiri menjadi `sticky top-6 flex flex-col gap-5`.
- [ ] **Step 3: Bangun Hero Form Card.** Desain form nama dan *scope* dalam bungkus `<div class="rounded-2xl border border-gray-200 bg-white p-6 shadow-card">`.
- [ ] **Step 4: Integrasikan Header.** Tambahkan elemen *header* mini di dalam form (misal: "Identitas Peran") dengan ikon `badge`.
- [ ] **Step 5: Percantik Tombol Aksi.** Ubah tombol "Simpan" menjadi `bg-brand-600 hover:bg-brand-700` dan tombol "Batal" menjadi varian sekunder yang bersih.

### Task 2: Perombakan `_permission-matrix.blade.php`

**Files:**
- Modify: `resources/views/admin/roles/_permission-matrix.blade.php`

**Interfaces:**
- Consumes: `roleForm` Alpine component data.

- [ ] **Step 1: Ganti kontainer utama.** Ubah `<x-panel>` luar matriks menjadi `<div class="rounded-2xl border border-gray-200 bg-white shadow-card">`.
- [ ] **Step 2: Rombak Toolbar (Header Matriks).** Ganti tombol "Pilih Semua", "Kosongkan", "Sync Permission" agar menggunakan UI kancing (Button UI) terbaru dengan warna teks `gray-700` atau `brand-600`.
- [ ] **Step 3: Rombak Audit Banner.** Ganti desain kotak kuning (`signal-amber`) ke `bg-amber-50 border-amber-200 text-amber-800`.
- [ ] **Step 4: Tata ulang Kotak Modul.** Ganti kotak pinggiran tiap modul menjadi *card* terpisah `rounded-xl border border-gray-200 bg-gray-50/50 p-5`.
- [ ] **Step 5: Percantik Checkboxes.** Terapkan kelas `text-brand-600 focus:ring-brand-500 border-gray-300` pada semua input `type="checkbox"`.
